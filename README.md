# Chrome AI Summarizer 🔍  

Chrome AI Summarizer is a lightweight Chrome Extension that uses Chrome’s **built-in Gemini Nano AI Summarizer API** to instantly summarize any webpage text.  
It’s private, fast, and works even offline!

---

## 🚀 Features
- Summarizes long text instantly  
- Works offline using on-device AI  
- Protects your privacy — no data sent to servers  
- Clean, minimal popup interface  

---

## 🧠 How It Works
This extension interacts with Chrome’s built-in **Summarizer API** to extract key points and generate a clear summary in seconds.  
It uses local AI (Gemini Nano) — meaning no external calls, just your device power ⚡

## 💡 How to Install
1. Download this repository as ZIP or clone it:
git clone https://github.com/ayush8789/chrome-ai-summarizer.git

yaml
2. Open Chrome → `chrome://extensions/`
3. Turn on **Developer Mode**
4. Click **Load unpacked**
5. Select the `chrome-ai-summarizer` folder  
6. Pin the extension from the puzzle icon and start summarizing any webpage!
